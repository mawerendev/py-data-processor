# Script de Análisis de Texto en Python

Un script sencillo y modular en Python que procesa cadenas de texto desde la terminal para calcular métricas básicas como el número de caracteres y palabras.

## Requisitos
- Python 3.10 o superior

## Cómo ejecutarlo

1. Clona el repositorio:
   ```bash
   git clone [https://github.com/mawerendev/mi-primer-codigo.git](https://github.com/mawerendev/mi-primer-codigo.git)
   cd mi-primer-codigo
Activa el entorno virtual:

Windows: .\venv\Scripts\Activate.ps1

Linux/Mac: source venv/bin/activate

  Ejecuta el script:

Bash



python main.py
